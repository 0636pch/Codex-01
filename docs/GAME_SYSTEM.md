# 게임 시스템

## 1. 설계 목표

게임 시스템은 몸의 결과를 채점하지 않고 건강한 행동의 반복을 강화합니다. 사용자는 무엇을 해서 보상을 받았는지 이해할 수 있어야 하며, 하루를 놓쳐도 기존 성장이 사라지지 않아야 합니다.

## 2. 성장 구조

```text
기록 행동 → 경험치 장부 → 전체 레벨
          ├→ 능력치 변화
          ├→ 퀘스트 진행
          └→ 의상·장비·칭호 해금

7일 추세 또는 새 인바디 → 안정화 규칙 → 캐릭터 성장 단계
```

전체 레벨과 캐릭터 성장 단계는 서로 다릅니다. 레벨은 꾸준한 행동으로 즉시 성장할 수 있지만, 체형 단계는 충분한 기간의 추세가 있을 때만 천천히 변합니다.

## 3. 경험치

### 경험치를 주는 행동

- 유효한 운동 세션 완료
- 운동 세부 기록 작성
- 식사 기록 완료(섭취량의 많고 적음이 아니라 기록 행동)
- 체중 또는 인바디 측정 기록
- 일일·주간 퀘스트 완료
- 안전한 범위의 연속 기록 보너스

### 경험치를 주지 않는 결과

- 체중 감소량 자체
- 적은 섭취 칼로리 또는 식사 생략
- 높은 운동 소모 칼로리 자체
- 체지방률이 특정 값에 도달한 것 자체
- 하루에 같은 기록을 반복 생성하는 행동

### MVP 계산 원칙

- 모든 지급은 `XpTransaction`에 근거와 규칙 버전을 남긴다.
- 같은 원본 기록에는 한 번만 지급한다.
- 기록 수정으로 경험치가 악용되지 않도록 최초 유효 저장 기준과 재계산 정책을 둔다.
- 하루 반복 입력에 상한 또는 감소 보상을 둘 수 있다.
- 정확한 지급량과 레벨 곡선은 사용자 테스트 후 확정한다.

예시 구조이며 수치는 확정하지 않습니다.

```text
획득 경험치 = 기본 기록 XP + 완료도 보너스 + 퀘스트 XP + 연속 기록 보너스
```

## 4. 능력치

| 능력치 | 의미 | 주로 반영하는 행동 |
|---|---|---|
| 근력 | 근력 훈련의 누적 참여 | 유효한 근력운동 기록, 관련 주간 퀘스트 |
| 지구력 | 지속적인 유산소·걷기 참여 | 유산소, 걷기, 지속 시간 기반 퀘스트 |
| 꾸준함 | 계획과 기록을 이어가는 습관 | 활동일, 일일·주간 퀘스트, 다양한 기록 |
| 회복력 | 휴식과 회복을 존중하는 습관 | 휴식일 체크인, 무리하지 않는 계획, 추후 회복 기록 |

MVP에서 수면·통증·피로 기록을 받지 않는다면 회복력의 근거가 약해질 수 있습니다. 이 경우 회복력은 제한적으로 운영하거나 회복 체크인을 MVP에 추가할지 결정해야 합니다.

능력치는 서로 우열을 판단하는 점수가 아니며, 감소나 페널티는 최소화합니다. 오랫동안 쉬어도 획득한 능력치를 대폭 잃지 않습니다.

## 5. 퀘스트

### 일일 퀘스트 후보

- 오늘의 운동 또는 활동 기록 남기기
- 식사 한 끼를 사실대로 기록하기
- 오늘 상태 확인하기

모든 사용자에게 매일 운동을 요구하지 않습니다. 목표·경험 수준·활동 계획에 따라 휴식형 퀘스트도 배정할 수 있습니다.

### 주간 퀘스트 후보

- 본인이 정한 횟수만큼 운동 기록하기
- 서로 다른 날에 활동 기록 남기기
- 주간 기록 돌아보기
- 새 체중 또는 선택적 인바디 기록하기(자주 측정하도록 압박하지 않음)

퀘스트는 목표에 맞춰 개인화하되 의료 처방처럼 표현하지 않습니다. 실패한 퀘스트는 `실패` 대신 `이번 주 미완료`처럼 중립적으로 표시합니다.

## 6. 연속 기록

- 연속 기록의 기준은 `하루에 하나 이상의 유효한 건강 행동 기록`을 기본 후보로 한다.
- 시간대는 사용자 설정 시간대를 따른다.
- 연속 기록이 끊겨도 레벨, 능력치, 보상은 회수하지 않는다.
- 과도한 기록을 유도하지 않도록 하루 보너스는 한 번만 지급한다.
- 휴식일 인정과 연속 기록 보호권은 추후 결정한다.

## 7. 의상·장비·칭호

- 보상은 외형 꾸미기와 성취 표현이 중심이며 운동 성과를 왜곡하는 능력치 유료 강화는 사용하지 않는다.
- 해금 조건 예: 레벨 도달, 첫 주간 퀘스트 완료, 다양한 운동 유형 기록
- 칭호는 `7일 기록 탐험가`처럼 행동을 기념하고 몸을 평가하지 않는다.
- 특정 게임의 명칭, 실루엣, 등급 색상 체계를 그대로 복제하지 않는다.

MVP는 소수의 기본 보상 세트로 시작하고, 시즌·희귀도·컬렉션은 이후 기능으로 둡니다.

## 8. 즉시 피드백

운동 저장 직후 다음 순서로 보여줍니다.

1. 저장 성공
2. 획득 경험치와 지급 이유
3. 레벨업 또는 능력치 변화
4. 퀘스트 진행 또는 완료
5. 새 보상 해금

모션 감소 설정을 존중하고, 이펙트가 끝나기 전에도 화면을 벗어날 수 있어야 합니다.

## 9. 캐릭터 체형 성장

### 입력과 안정화

- 기본 체형은 사용자가 캐릭터 생성 시 직접 선택한다.
- 변화 계산은 최근 7일의 충분한 측정 추세 또는 새 인바디 결과를 사용한다.
- 단일 체중 기록, 단일 식사, 하루 운동만으로 단계가 바뀌지 않는다.
- 수분, 측정 시간, 기기 차이에 따른 변동을 고려해 변화 임계값과 대기 기간을 둔다.
- 단계 변화는 가치 판단이 아닌 `변화가 반영됨`으로 설명한다.

### 안전 장치

- 급격한 감량이나 낮은 섭취를 성장 조건으로 사용하지 않는다.
- 데이터가 부족하면 현재 단계를 유지한다.
- 잘못 입력한 값은 제외하거나 수정할 수 있게 한다.
- 사용자가 체형 변화 표시를 끄거나 기본 체형을 유지할 수 있는 옵션을 검토한다.

정확한 단계 수, 임계값, 근육·체지방 추세 조합식은 건강 전문가 검토와 사용자 테스트 전에는 확정하지 않습니다.

## 10. 부정 사용 방지

- 원본 기록 ID 기준 중복 경험치 차단
- 비정상적으로 반복되는 동일 기록의 보상 제한
- 수정·삭제 시 경험치 조정 기록 보존
- 사용자에게 불필요한 감시감을 주지 않도록 제한 이유 설명

## 11. 나중에 추가할 기능

- 시즌 퀘스트와 확장 보상
- 친구 협동 퀘스트
- 웨어러블 기반 자동 퀘스트 판정
- 더 정교한 회복 기록과 개인화
- 캐릭터 애니메이션과 배경 공간 꾸미기

## 12. 추후 결정 사항

- 행동별 경험치, 일일 상한, 레벨 곡선
- 능력치 최대치와 증가 공식
- 회복 체크인을 MVP에 넣을지 여부
- 퀘스트 자동 수령 또는 수동 수령
- 연속 기록 인정 조건, 유예 시간, 휴식일 처리
- 체형 성장 단계 수, 명칭, 임계값, 최소 데이터 수
- 보상 등급과 해금 목록
- 기록 수정·삭제 시 경험치 회수 정책
