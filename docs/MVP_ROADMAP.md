# MVP 로드맵

## 1. 목표

첫 MVP는 사용자가 안전하게 가입하고, 캐릭터를 만든 뒤, 운동·식사·체중을 기록하여 즉시 게임 성장을 확인하는 하나의 완결된 흐름을 제공하는 것이 목표입니다.

## 2. 단계별 개발 순서

### 0단계: 미결정 사항 확정

- 인증과 데이터 저장 방식
- 최소 연령 및 동의 정책
- 경험치·레벨·퀘스트의 초기 수치
- 캐릭터 에셋 규격과 성장 단계 표현
- 칼로리 추정 출처와 안전 안내 기준

완료 기준: 제품, 디자인, 개발, 개인정보 담당자가 같은 용어와 MVP 범위에 합의함.

### 1단계: UX 뼈대와 디자인 기반

- 사용자 흐름과 하단 탐색 구조 확정
- 색상, 글꼴, 간격, 버튼, 입력창, 카드 등 디자인 토큰 정의
- 로딩·빈 상태·오류·성공 패턴 설계
- 캐릭터 파츠 레이어 규격 정의
- 접근성 및 중립적 문구 검토

완료 기준: 필수 12개 화면의 저해상도 와이어프레임과 클릭 가능한 흐름이 검토됨.

### 2단계: 계정과 온보딩

- 시작, 회원가입, 로그인
- 개인정보 및 건강 데이터 동의
- 기본 정보, 선택적 인바디
- 캐릭터 만들기

완료 기준: 신규 사용자가 가입부터 캐릭터 생성까지 완료하고, 중단·오류 상황에서도 안전하게 복구할 수 있음.

### 3단계: 기록 기능

- 운동 기록
- 식사·영양 기록
- 체중 및 인바디 추가
- 입력 검증, 수정, 삭제
- 섭취 칼로리와 활동 칼로리 분리 집계

완료 기준: 각 기록이 정확한 사용자와 날짜에 저장되고 수정·삭제·중복 저장 방지가 시험됨.

### 4단계: 핵심 게임 루프

- 경험치 장부와 레벨 계산
- 네 능력치
- 일일·주간 퀘스트
- 연속 기록
- 운동 저장 직후 피드백
- 기본 의상·장비·칭호 해금

완료 기준: 동일 기록에 경험치가 중복 지급되지 않고, 모든 변화 이유를 사용자와 운영자가 추적할 수 있음.

### 5단계: 대시보드와 성장

- 오늘 기록, 퀘스트, 캐릭터 통합 대시보드
- 성장 그래프
- 7일 추세 및 인바디 기반 성장 스냅샷
- 캐릭터·능력치와 보상 장착

완료 기준: 단일 기록으로 체형이 급변하지 않으며 데이터 부족, 이상값, 기록 수정 상황이 처리됨.

### 6단계: 설정, 권리, 출시 준비

- 프로필·알림·단위 설정
- 동의 내역과 철회
- 데이터 내보내기
- 계정 및 데이터 삭제
- 보안·성능·접근성·개인정보 점검
- Android 내부 테스트 배포 준비

완료 기준: 핵심 흐름, 삭제, 복구, 권한, 네트워크 실패 시나리오를 통과하고 출시 체크리스트가 승인됨.

## 3. 가장 먼저 구현할 화면

개발 시작 시 첫 화면 묶음은 **캐릭터가 포함된 메인 대시보드의 정적 프로토타입**을 권장합니다. 이 화면이 기록, 성장, 퀘스트, 칼로리 분리 표시를 한곳에 연결하므로 제품의 핵심 구조와 데이터 계약을 가장 빨리 검증할 수 있습니다.

그 다음 실제 기능 구현 순서는 `시작 → 회원가입/로그인 → 동의 → 기본 정보 → 인바디 → 캐릭터 만들기`입니다. 사용자가 대시보드에 도달하는 안전한 경로가 먼저 필요하기 때문입니다.

## 4. MVP 출시 범위

### 반드시 포함

- Android 핵심 흐름
- 직접 입력 방식의 운동·식사·체중·인바디 기록
- 기본 캐릭터 파츠
- 레벨, 경험치, 네 능력치
- 일일·주간 퀘스트와 연속 기록
- 기본 성장 그래프와 안정화된 체형 단계
- 동의, 데이터 내보내기, 계정·데이터 삭제
- 칼로리 추정값 표시와 안전 문구

### 일정에 따라 축소 가능한 항목

- 보상 파츠 개수
- 그래프 기간 선택의 다양성
- 운동·음식 최근 기록 복사
- 고급 캐릭터 이펙트
- 복잡한 퀘스트 개인화

안전, 동의, 삭제 기능은 일정 때문에 제외하지 않습니다.

## 5. MVP 이후

### 2차

- iOS 정식 지원
- 웨어러블·헬스 플랫폼 연동
- 음식 검색과 바코드 입력
- 더 많은 캐릭터 파츠와 시즌 퀘스트
- 회복·수면 체크인

### 장기 후보

- 친구 협동과 비공개 그룹 도전
- 고급 리포트와 전문가 공유
- 음식·운동 자동 인식
- 얼굴 사진 기반 기능은 별도 보안·동의·법률 검토 후 재평가

공개 순위, 체중 비교, 경쟁 중심 기능은 제품 원칙과 안전성 검토를 통과한 경우에만 고려합니다.

## 6. 테스트 전략

- 단위 테스트: 경험치, 레벨, 퀘스트, 연속 기록, 7일 추세 계산
- 통합 테스트: 기록 저장 후 대시보드·게임 진행 갱신
- 시나리오 테스트: 가입 중단, 네트워크 실패, 중복 탭, 시간대 변경, 과거 기록 수정
- 개인정보 테스트: 권한 분리, 로그 마스킹, 내보내기, 삭제, 백업 반영
- UX 테스트: 초보자가 5분 안에 첫 기록을 완료하는지 확인
- 안전 문구 테스트: 죄책감이나 체형 평가로 받아들여지는 표현이 없는지 확인

## 7. 출시 판단 기준

- 치명적 데이터 손실·중복 경험치 문제가 없음
- 계정 삭제와 동의 철회가 문서대로 동작함
- 단일 측정으로 캐릭터 체형이 급변하지 않음
- 칼로리의 추정값·분리 표시가 모든 관련 화면에서 일관됨
- 접근성 핵심 항목과 주요 Android 기기에서 사용 가능함
- 개인정보·건강 안전 검토가 완료됨

## 8. 추후 결정 사항

- MVP 목표 일정과 참여 인원
- 백엔드·인증·분석 기술 선택
- 디자인 시스템과 2D 에셋 제작 방식
- 지원 Android 최소 버전과 테스트 기기
- MVP에서 지원할 운동 종류와 입력 깊이
- 초기 퀘스트·보상 콘텐츠 수
- 회복 체크인과 체형 고정 옵션의 MVP 포함 여부
- 베타 사용자 모집 및 피드백 방식
