# 개인정보 및 안전

## 1. 문서 목적

이 문서는 제품 설계 기준입니다. 실제 출시 전에는 서비스 대상 국가의 개인정보·건강정보 관련 법률, 앱스토어 정책, 미성년자 보호 요건에 대해 법률 검토가 필요합니다.

## 2. 데이터 분류

### 계정 데이터

- 이메일, 닉네임, 인증 정보
- 로그인 및 보안 기록

### 건강·신체 데이터

- 나이, 키, 체중, 운동 목적, 경험 수준, 활동량
- 골격근량, 체지방량, 체지방률, BMI, 내장지방 수준
- 운동, 식사, 칼로리, 영양소 기록

건강·신체 데이터는 민감한 정보로 취급합니다. 얼굴 사진은 MVP에서 수집하지 않습니다.

### 게임·앱 사용 데이터

- 레벨, 경험치, 능력치, 퀘스트, 연속 기록, 보상
- 알림과 단위 설정
- 분석 이벤트는 별도 승인 범위를 확정한 뒤 최소 수집

## 3. 동의 원칙

- 필수 동의와 선택 동의를 분리한다.
- 수집 항목, 목적, 보관 기간, 제3자 제공, 국외 이전 여부를 알기 쉽게 설명한다.
- 사용자가 본 문서 버전과 동의 시각을 기록한다.
- 선택 동의를 거절해도 핵심 기능을 가능한 범위에서 사용할 수 있게 한다.
- 동의 철회 경로를 설정에서 쉽게 찾을 수 있게 한다.
- 처리 목적이 바뀌면 새 동의가 필요한지 검토한다.

## 4. 최소 수집과 목적 제한

- 캐릭터 생성에 얼굴 사진을 요구하지 않는다.
- 인바디는 선택 입력이며 건너뛰어도 앱을 사용할 수 있다.
- 목적이 분명하지 않은 기기 식별자, 연락처, 위치는 수집하지 않는다.
- 공개 소셜 기능이 없으므로 건강 기록은 기본적으로 비공개다.
- 개발·분석 로그에 이메일, 식사 내용, 인바디 원문을 남기지 않는다.

## 5. 보안 기준

- 전송 중 암호화와 저장 시 암호화를 적용한다.
- 비밀번호는 검증된 해시 또는 인증 제공자를 사용하고 원문 저장을 금지한다.
- 건강 데이터 접근 권한은 업무상 필요한 최소 인원과 서비스만 갖는다.
- 운영자 접근 기록과 중요 변경 감사 로그를 남긴다.
- 인증 토큰은 모바일 보안 저장소를 사용하고 로그에 출력하지 않는다.
- 백업도 본 데이터와 같은 수준으로 보호하고 삭제 정책에 포함한다.
- 사고 대응, 사용자 통지, 키 교체 절차를 출시 전에 마련한다.

구체적인 암호화 제품과 보관 지역은 인프라 선정 후 결정합니다.

## 6. 사용자 권리

사용자는 다음을 할 수 있어야 합니다.

- 자신의 프로필과 기록 확인·수정
- 동의 내역 확인과 선택 동의 철회
- 데이터 내보내기 요청
- 계정과 연결 데이터 삭제 요청
- 처리 상태 및 문의 경로 확인

삭제 화면은 사라지는 데이터, 처리 예상 기간, 법적 보관 예외, 백업 반영 기간을 설명하고 재인증을 요구합니다.

## 7. 칼로리 및 섭식 안전

- 섭취 칼로리와 활동 칼로리를 별도 표시한다.
- 모든 자동 계산값에 `추정값`임을 명시한다.
- `섭취 - 운동 = 허용량`처럼 운동으로 음식을 상쇄하도록 유도하지 않는다.
- 적게 먹기, 식사 거르기, 큰 적자를 경험치 조건으로 사용하지 않는다.
- 극단적인 값이 반복되면 비난 없이 계산 한계와 전문 도움을 안내한다.
- 구체적인 경고 기준은 연령, 사용자 맥락, 오탐 위험을 고려해 건강·법률 전문가 검토 후 정한다.

## 8. 체중·외모 안전

- `나쁜 체형`, `실패한 몸`, `정상에서 벗어남` 같은 평가 표현을 쓰지 않는다.
- 체중 변화의 방향을 제품 성공이나 사용자 가치와 연결하지 않는다.
- 측정값은 수분, 시간, 장비에 따라 달라질 수 있음을 안내한다.
- 캐릭터 체형은 단일 기록에 반응하지 않고, 표시를 원치 않는 사용자를 위한 고정 옵션을 검토한다.
- 다른 사용자와 체중·체지방을 공개 비교하지 않는다.

## 9. 의료 안전

앱은 운동 및 식사 기록 도구이며 의료기기가 아닙니다. 질병 진단, 위험도 판정, 치료·식단·운동 처방을 제공하지 않습니다. 통증, 실신, 섭식 문제 등 즉각적인 도움이 필요한 상황을 앱이 판단하려 시도하지 않고, 사용자가 우려를 표현한 경우 지역의 의료 전문가나 긴급 지원을 찾도록 일반적인 안내를 제공합니다.

## 10. 미성년자

지원 최소 연령, 보호자 동의, 연령 확인 방식, 데이터 사용 제한은 출시 국가 법률 검토 후 결정합니다. 결정 전에는 미성년자 대상 마케팅과 소셜 기능을 설계하지 않습니다.

## 11. 보존·삭제 정책 초안

- 계정 활성 중: 기능 제공에 필요한 기간만 보관
- 계정 삭제 요청: 본인 확인 후 처리 상태 기록
- 백업: 정해진 순환 주기 이후 제거
- 법적 보관: 필요한 항목만 분리 보관하고 목적 외 사용 금지
- 익명 분석: 재식별 위험을 검토한 뒤에만 유지

구체 기간은 임의로 확정하지 않습니다.

## 12. 출시 전 점검표

- 개인정보 처리방침과 동의 문구 법률 검토
- 데이터 흐름도와 제3자 목록 작성
- 접근 권한, 암호화, 백업·복원 시험
- 계정 삭제와 내보내기 종단 간 시험
- 로그·분석 도구의 민감정보 유출 점검
- 칼로리·체형 문구에 대한 건강 전문가 및 사용자 테스트
- 스토어 건강 데이터 정책 확인

## 13. 추후 결정 사항

- 서비스 국가와 준거 법률
- 최소 가입 연령과 보호자 동의 방식
- 데이터 저장 국가·제3자 처리자·국외 이전 여부
- 보관 기간, 삭제 유예, 백업 제거 기간
- 칼로리 안전 안내 기준과 전문 도움 링크
- 분석 및 오류 수집 도구와 익명화 수준
- 체형 변화 끄기 옵션의 MVP 포함 여부
- 보안 사고 대응 책임자와 문의 채널
