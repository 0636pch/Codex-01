# 제품 명세서

## 1. 제품 정의

Body Quest는 운동 일지를 쓰는 행동을 RPG의 성장 경험으로 바꾸는 모바일 앱입니다. 기록 직후에는 경험치와 시각 효과로 즉각적인 만족을 주고, 실제 신체 추세는 느리고 안정적으로 캐릭터에 반영합니다.

## 2. 해결하려는 문제

- 운동 기록 앱은 숫자가 많아 초보자가 지속하기 어렵다.
- 체중 변화는 느리고 흔들림이 커서 단기 동기 부여 수단으로 부적절하다.
- 체중 감량만 보상하면 과도한 식사 제한이나 부정적인 자기 평가를 유도할 수 있다.

Body Quest는 기록, 운동 수행, 회복 관리 같은 사용자가 통제 가능한 행동을 보상하여 이 문제를 완화합니다.

## 3. 주요 사용자

- 운동을 시작했지만 기록 습관이 없는 사람
- 숫자 중심 건강 앱보다 게임형 피드백을 선호하는 사람
- 근육 증가, 체력 향상, 유지 또는 체중 감량 목표를 장기적으로 관리하려는 사람

연령 제한은 법률·스토어 정책·데이터 처리 방식 검토 후 결정합니다.

## 4. 성공 경험

사용자는 가입 후 5분 안에 캐릭터를 만들고 첫 기록을 남길 수 있어야 합니다. 기록 직후 경험치 증가 이유가 명확히 보여야 하며, 일주일 뒤에는 그래프와 캐릭터 성장 단계로 자신의 꾸준함을 확인할 수 있어야 합니다.

## 5. 제품 원칙

1. 체중이나 외모를 평가하는 표현을 사용하지 않는다.
2. 체중 감소량이나 낮은 섭취량 자체에는 경험치를 지급하지 않는다.
3. 운동과 기록의 꾸준함을 중심으로 보상한다.
4. 칼로리 수치는 추정값으로 표시하고 섭취량과 활동량을 상쇄 계산해 보상하지 않는다.
5. 의료 진단·처방처럼 보이는 문구를 제공하지 않는다.
6. 인바디와 계정 정보는 민감한 데이터로 분류해 최소 수집한다.
7. 캐릭터 외형과 인터페이스는 독창적으로 설계한다.

## 6. 1차 MVP 기능 요구사항

### 계정과 온보딩

- 이메일, 비밀번호, 닉네임 입력
- 개인정보 및 건강 데이터 처리 동의
- 나이, 키, 체중, 운동 목적, 운동 경험 수준, 평소 활동량 입력
- 인바디 선택 입력: 측정일, 체중, 골격근량, 체지방량, 체지방률, BMI, 내장지방 수준
- 2D 캐릭터 파츠 선택: 얼굴형, 머리, 피부색, 기본 체형, 운동복

### 기록

- 운동: 날짜, 운동 종류, 시간, 세트·횟수·중량 또는 거리·시간 등 종류별 세부값, 예상 소모 칼로리
- 식사: 날짜와 끼니, 음식명, 섭취량, 칼로리, 단백질·탄수화물·지방
- 체중: 날짜, 체중
- 인바디: 온보딩 후에도 새 결과 추가
- 사용자가 직접 입력한 값과 앱이 추정한 값을 구분

### 성장과 게임

- 전체 레벨, 현재 경험치, 다음 레벨 필요 경험치
- 근력, 지구력, 꾸준함, 회복력
- 일일·주간 퀘스트와 완료 상태
- 연속 기록 일수
- 의상, 장비, 칭호 해금 및 장착
- 운동 저장 직후 경험치 획득 사유와 이펙트 표시
- 최근 7일 추세 또는 새 인바디를 반영한 단계적 체형 변화

### 확인과 제어

- 대시보드에서 오늘의 기록, 퀘스트, 경험치, 캐릭터 확인
- 성장 그래프에서 체중·신체 조성·운동량·꾸준함 지표를 선택해 확인
- 설정에서 동의 내역, 알림, 데이터 내보내기, 계정 및 데이터 삭제 접근

## 7. MVP 비기능 요구사항

- Android 우선, iOS 확장을 막는 플랫폼 종속 설계 최소화
- 네트워크 실패 중 입력 내용 보존 및 중복 저장 방지
- 주요 화면에 로딩, 빈 상태, 오류, 재시도 상태 제공
- 민감정보 전송·저장 암호화 및 접근 통제
- 글자 확대, 색상 외 표시, 충분한 터치 영역 등 기본 접근성 지원
- 경험치 계산은 서버 또는 검증 가능한 공통 규칙에서 수행하여 조작과 불일치 방지

## 8. MVP에서 제외

- 얼굴 사진 업로드 및 얼굴 기반 캐릭터 생성
- 자동 운동 인식, 웨어러블과 건강 플랫폼 연동
- 소셜 피드, 길드, PvP, 공개 순위
- 의료 상담, 질병 위험도 판단, 개인 맞춤 처방
- 음식 사진·바코드 인식과 대규모 음식 DB
- 유료 상품과 광고

## 9. 핵심 지표 후보

출시 전 분석 동의와 데이터 최소 수집 원칙을 확정한 뒤 측정합니다.

- 가입 후 첫 기록 완료율
- 7일 및 30일 기록 유지율
- 주간 운동 기록 사용자 비율
- 퀘스트 완료율
- 데이터 삭제 요청 처리 성공률
- 칼로리 경고 또는 안전 안내 노출 후의 이탈·불편 신고

체중 감소량은 제품 성공의 핵심 지표로 사용하지 않습니다.

## 10. 추후 결정 사항

- 지원 최소 연령과 미성년자 가입 방식
- 이메일 인증·비밀번호 재설정 제공자
- 오프라인 기록 범위와 동기화 충돌 규칙
- 알림 종류, 기본값, 발송 시간
- 유료화 여부와 범위
- 접근성 목표 수준과 지원 언어
- 분석 도구 및 수집 이벤트의 구체적인 목록
