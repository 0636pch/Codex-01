# 화면 목록

## 화면과 데이터 관계 요약

| 번호 | 화면 | 읽는 주요 데이터 | 생성·수정하는 데이터 |
|---|---|---|---|
| 1 | 시작 | 앱 소개 | 없음 |
| 2 | 회원가입·로그인 | 계정 상태 | 사용자 계정, 인증 세션 |
| 3 | 동의 | 동의 문서 버전 | 사용자 동의 내역 |
| 4 | 기본 정보 | 사용자 프로필 | 신체·목표 프로필 |
| 5 | 인바디 입력 | 최근 측정값 | 인바디 측정 결과 |
| 6 | 캐릭터 만들기 | 사용 가능한 파츠 | 캐릭터 외형 설정 |
| 7 | 메인 대시보드 | 오늘 기록, 성장, 퀘스트 | 빠른 기록 진입, 퀘스트 확인 |
| 8 | 운동 기록 | 운동 유형, 최근 기록 | 운동 세션·운동 항목 |
| 9 | 식사·칼로리 기록 | 당일 식사 요약 | 식사·음식 항목 |
| 10 | 성장 그래프 | 체중, 인바디, 운동 집계 | 체중·인바디 추가 진입 |
| 11 | 캐릭터·능력치 | 성장 상태, 보상 | 장착 외형·칭호 |
| 12 | 설정·데이터 삭제 | 계정, 동의, 설정 | 설정, 동의 철회, 삭제 요청 |

## 1. 시작 화면

- 목적: 제품의 가치와 안전한 방향을 짧게 소개
- 주요 요소: 로고, 한 문장 설명, 회원가입, 로그인
- 상태: 기본, 네트워크 오류
- MVP: 포함

## 2. 회원가입과 로그인

- 목적: 계정 생성 및 기존 계정 인증
- 입력: 이메일, 비밀번호, 닉네임(가입 시)
- 주요 동작: 가입, 로그인, 비밀번호 찾기 진입
- 검증: 이메일 형식, 비밀번호 정책, 닉네임 허용 규칙
- 상태: 입력 중, 제출 중, 오류, 성공
- MVP: 포함

## 3. 개인정보 및 건강 데이터 동의

- 목적: 수집 목적과 권리를 이해한 상태에서 동의 받기
- 주요 요소: 필수/선택 구분, 문서 버전, 자세히 보기, 동의 철회 안내
- 저장: 동의 종류, 문서 버전, 동의 시각, 철회 시각
- MVP: 포함

## 4. 기본 정보 입력

- 목적: 초기 목표와 신체 기준값 설정
- 입력: 나이, 키, 체중, 운동 목적, 운동 경험 수준, 평소 활동량
- UX: 단위 명시, 선택 이유 설명, 나중에 수정 가능함을 안내
- 저장: 사용자 프로필과 첫 체중 측정값
- MVP: 포함

## 5. 인바디 입력

- 목적: 선택적인 신체 조성 기준값 저장
- 입력: 측정일, 체중, 골격근량, 체지방량, 체지방률, BMI, 내장지방 수준
- UX: `선택 입력`, `기기·조건에 따라 달라질 수 있음`, 건너뛰기
- 저장: 하나의 측정 시점에 속한 인바디 묶음
- MVP: 포함

## 6. 캐릭터 만들기

- 목적: 사용자가 자신을 표현하는 독창적인 2D 캐릭터 구성
- 선택: 얼굴형, 머리, 피부색, 체형, 운동복
- UX: 실시간 미리보기, 파츠 이름, 무작위 조합, 완료
- 주의: 체형 선택에 가치 판단 표현을 붙이지 않음
- MVP: 기본 파츠와 색상 포함

## 7. 메인 대시보드

- 목적: 오늘 해야 할 행동과 성장 상태를 한눈에 제공
- 주요 요소: 캐릭터, 레벨·경험치, 오늘 기록 요약, 섭취/활동 칼로리 분리 카드, 일일·주간 퀘스트, 연속 기록, 빠른 기록 버튼
- 데이터: 사용자, 성장 상태, 오늘 기록 집계, 퀘스트 진행도
- 상태: 첫 사용 빈 상태, 일부 기록, 완료, 로딩, 오류
- MVP: 포함

## 8. 운동 기록

- 목적: 근력운동, 유산소, 걷기 기록
- 공통 입력: 날짜·시각, 유형, 운동명, 시간, 메모
- 근력 입력: 세트별 횟수와 중량
- 유산소·걷기 입력: 시간, 거리, 강도 또는 걸음 수(선택)
- 칼로리: 예상 소모량, 산정 출처, 추정값 표시
- 완료 피드백: 획득 경험치, 능력치 변화, 퀘스트 진척
- MVP: 직접 입력 중심

## 9. 식사 및 칼로리 기록

- 목적: 끼니와 영양소 기록
- 입력: 날짜·시각, 아침/점심/저녁/간식, 음식명, 섭취량과 단위, 칼로리, 단백질, 탄수화물, 지방
- 표시: 하루 섭취 합계와 활동 칼로리를 서로 다른 영역에 표시
- 주의: 순칼로리를 점수나 보상으로 사용하지 않음
- MVP: 직접 입력 및 최근 음식 재사용 여부는 추후 결정

## 10. 성장 그래프

- 목적: 단기 숫자보다 기간별 추세 이해
- 지표: 체중, 골격근량, 체지방량, 체지방률, 운동 횟수·시간, 기록 일수
- 조작: 7일/30일/사용자 지정 기간, 지표 선택
- 표현: 데이터가 부족하면 판단 대신 더 기록할 것을 안내
- 입력 진입: 체중 추가, 인바디 추가
- MVP: 핵심 지표 그래프 포함

## 11. 캐릭터와 능력치

- 목적: 게임 성장과 실제 기록의 연결을 설명
- 주요 요소: 캐릭터, 전체 레벨, 경험치, 근력·지구력·꾸준함·회복력, 체형 성장 단계, 변화 근거, 해금한 의상·장비·칭호
- 동작: 외형 및 칭호 장착
- 상태: 신규 해금, 다음 보상 미리보기, 최대 단계
- MVP: 기본 보상 세트 포함

## 12. 설정 및 데이터 삭제

- 목적: 계정, 알림, 단위, 동의와 데이터 권리 관리
- 주요 요소: 프로필 수정, kg/cm 단위, 알림, 동의 내역, 개인정보 안내, 데이터 내보내기, 로그아웃, 계정 및 데이터 삭제
- 삭제 UX: 재인증, 영향 설명, 최종 확인, 처리 상태
- MVP: 포함

## 공통 UI 규칙

- 칼로리 옆에는 추정값 여부와 산정 출처를 확인할 수 있게 한다.
- 체중·체형에 `성공/실패`, `좋음/나쁨` 같은 평가를 붙이지 않는다.
- 색만으로 완료·오류를 구분하지 않는다.
- 저장 버튼은 중복 탭을 방지하고, 실패 시 입력값을 유지한다.
- 의료적 판단이 필요한 상황에는 앱의 한계를 밝히고 전문가 상담을 안내한다.

## 나중에 추가할 화면

- 친구·길드·그룹 퀘스트
- 웨어러블 및 헬스 데이터 연동
- 음식 검색·바코드·사진 입력
- 시즌 패스 및 확장 보상 컬렉션
- 고급 리포트와 공유

## 추후 결정 사항

- 하단 탭 구성과 각 탭의 명칭
- 태블릿 및 가로 화면 지원 범위
- 캐릭터 애니메이션 수준과 접근성용 모션 감소 옵션
- 그래프 라이브러리와 시각 규칙
- 최근 음식·운동 복사 기능의 MVP 포함 여부
- 알림 설정의 세부 항목
