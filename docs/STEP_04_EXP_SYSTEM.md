# STEP 4 — EXP 및 능력치 계산 시스템

## 목표
운동 기록을 조작하기 어렵고 과훈련을 유도하지 않는 EXP로 변환한다. 최종 계산은 Cloud Functions가 수행한다.

## 1. 근력운동 점수
완료한 working set만 계산한다.

`세트볼륨 = 중량kg × 반복수`

`운동볼륨 = 모든 유효 세트볼륨 합`

`볼륨점수 = 18 × ln(1 + 운동볼륨 / 500)`

`시간점수 = min(운동시간분, 90) × 0.45`

`완료점수 = min(유효세트수, 20) × 2`

`근력기본EXP = round(20 + 볼륨점수 + 시간점수 + 완료점수)`

예: 벤치프레스 2,060kg, 35분, 3세트라면 약 72 EXP다. 로그 함수를 사용해 무거운 중량을 계속 추가해도 보상이 선형으로 폭증하지 않게 한다.

## 2. 유산소 EXP
`강도계수 = clamp(MET / 6, 0.6, 1.5)`

`유산소기본EXP = round(15 + min(시간분, 120) × 0.8 × 강도계수)`

심박수나 거리가 없으면 시간과 활동 종류의 표준 MET만 사용한다. 사용자가 직접 입력한 소비 칼로리는 EXP 근거로 직접 사용하지 않는다.

## 3. 발전 보너스
같은 운동의 최근 28일 기준과 비교한다.

- 볼륨 2~5% 향상: +10 EXP
- 볼륨 5~10% 향상: +20 EXP
- 볼륨 10% 이상 향상: +30 EXP
- 추정 1RM 개인기록: +40 EXP
- 동일 기록 반복: 보너스 없음

`추정1RM = 중량 × (1 + 반복수 / 30)` (Epley 공식, 1~12회 세트만)

## 4. 꾸준함 보너스
- 그날 첫 정상 운동 완료: +20
- 주간 목표 달성: +150
- 7일 기록 스트릭: +80
- 30일 스트릭: +250
- 하루 여러 번 운동해도 첫 완료 보너스는 1회

## 5. 피로도와 일일 제한
`피로계수 = max(0.55, 1 - max(0, 최근7일운동일수 - 4) × 0.10)`

`최종운동EXP = round((기본EXP + 발전보너스) × 피로계수) + 꾸준함보너스`

- 운동 EXP 일일 soft cap: 350
- 일일 hard cap: 500
- soft cap 초과분은 25%만 인정
- 주간 목표·업적 보너스는 별도지만 서버 중복키 적용
- 통증, 극단적 칼로리 적자, 체중 급감에는 보너스를 주지 않음

## 6. 부위별 EXP
운동 DB의 가중치를 사용한다.

예: 벤치프레스 100 EXP, `{chest: .65, arm: .20, shoulder: .15}`
- CHEST +65
- ARM +20
- SHOULDER +15

세션의 모든 운동을 합산한 뒤 반올림 오차는 주동근에 더한다.

## 7. 능력치 변환
능력치는 1~100이며 EXP 누적값을 완만한 곡선으로 변환한다.

`stat = min(100, floor(10 + 15 × ln(1 + relevantExp / 1000)))`

- STR: CHEST/BACK/SHOULDER/ARM/LEG 근력 EXP
- END: 근력 세션 시간, 반복량, 전신 운동
- CARDIO: CARDIO EXP
- BODY: 인바디의 장기 변화 점수 70% + 부위 성장 30%
- CONSISTENCY: 최근 12주 목표 달성률과 기록일수

## 8. 중복·수정 방지
`idempotencyKey = uid:sourceType:sourceId:algorithmVersion`

운동 수정 시 기존 원장을 삭제하지 않고 reversal 로그를 추가한 후 다시 계산한다. 모든 EXP 확정은 Firestore transaction으로 사용자 누계와 원장을 함께 갱신한다.
