# STEP 5 — 레벨 시스템

## 목표
초반에는 빠르게 성장하고 장기적으로는 완만해지는 1~50 레벨 구조를 만든다.

## 필요 누적 EXP
`누적필요EXP(level) = round(100 × (level - 1)^1.65)`

실제 서비스에서는 이 공식으로 생성한 값을 `levelDefinitions`에 저장해 운영 중 공식이 바뀌어도 기존 사용자에게 갑작스러운 변화가 없게 한다.

| 레벨 | 누적 필요 EXP(약) | 등급 |
|---:|---:|---|
| 1 | 0 | STARTER |
| 5 | 985 | STARTER |
| 10 | 3,752 | ROOKIE |
| 20 | 12,918 | TRAINER |
| 30 | 25,784 | ATHLETE |
| 40 | 41,822 | WARRIOR |
| 50 | 60,900 | ELITE |

## 등급 구간
- LV 1~5: STARTER
- LV 6~10: ROOKIE
- LV 11~20: TRAINER
- LV 21~30: ATHLETE
- LV 31~40: WARRIOR
- LV 41~50: ELITE

명칭과 범위는 DB 설정값으로 관리한다.

## 레벨 계산
누적 EXP가 여러 레벨 기준을 넘으면 한 트랜잭션에서 연속 레벨업한다.

- `currentLevelExp = totalExp - 현재레벨 누적기준`
- `nextLevelExp = 다음레벨 누적기준 - 현재레벨 누적기준`
- 50레벨 이후 EXP는 누적되지만 표시 레벨은 50
- 레벨은 내려가지 않는 것을 기본 정책으로 한다
- 부정 기록 취소 등 특수 보정은 관리자 감사 로그를 남긴다

## 보상
능력치를 직접 올리는 Pay-to-Win 보상은 사용하지 않는다.
- 레벨 3: 기본 운동복 색상
- 레벨 5: 배경
- 레벨 10: 신발
- 이후: 의상, 칭호, 캐릭터 연출

## UI
`LV.12  7,420 / 10,000`처럼 현재 레벨 내 진행도를 보여주며, 누적 EXP는 상세 화면에서 별도로 표시한다.
