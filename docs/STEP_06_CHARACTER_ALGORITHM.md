# STEP 6 — 캐릭터 변화 알고리즘

## 목표
운동 횟수만으로 몸이 바뀌지 않게 하고, 실제 신체 추세와 부위별 훈련을 조합해 2D 캐릭터의 단계값을 천천히 변경한다.

## 입력
- 최초 및 최근 체중
- 골격근량, 체지방률
- 최소 14일 이상 간격의 인바디
- 최근 8주 부위별 운동 EXP
- 데이터 개수와 측정 간격
- 사용자가 선택한 최초 기본 체형

## 기준선
캐릭터 생성 시 기준값을 저장한다. 새 측정 한 번으로 기준선을 바꾸지 않는다. 최근 3개 측정의 중앙값 또는 지수가중평균을 사용한다.

`추세값 = 최근값×0.5 + 이전값×0.3 + 그이전값×0.2`

측정 1개면 외형 변화 없이 기준선만 만든다.

## 신뢰도
- 인바디 1개: 0.25
- 2개이며 14일 이상: 0.55
- 3개 이상, 30일 이상: 0.80
- 3개 이상, 60일 이상: 1.00

## 체지방 단계
`fatDelta = 현재추세체지방률 - 기준체지방률`

`bodyFatStageChange = clamp(round(-fatDelta / 1.5), -3, 3) × confidence`

체지방률 1.5%p의 안정적 감소당 한 단계에 해당하지만 한 번 계산에서 최대 3단계만 움직인다.

## 근육 단계
`muscleRate = (현재골격근량 - 기준골격근량) / 기준골격근량 × 100`

`muscleStageChange = clamp(round(muscleRate / 2), -2, 3) × confidence`

골격근량 약 2% 변화당 한 단계이며 체수분 변동 영향을 줄이기 위해 최소 두 번의 측정에서 같은 방향이 확인돼야 한다.

## 부위별 변화
`부위점수 = 0.65 × 최근8주EXP정규화 + 0.35 × 최근4주지속률`

부위 외형은 실제 근육 변화 신뢰도가 있을 때만 크게 바뀐다. 운동 기록만 있을 때는 자세, 광택, 작은 선명도 등 가벼운 성장 표현만 허용한다.

- CHEST → chestStage
- BACK+SHOULDER → shoulderStage
- ARM → armStage
- LEG → legStage
- CORE와 체지방 추세 → waist/definitionStage

## 변화 속도 제한
- 외형 계산: 새 인바디 저장 시 및 주 1회
- 7일에 한 부위 최대 1단계
- 30일 최대 2단계
- 한 번의 체중 변화만으로 체형 변경 금지
- 반대 방향 변화도 같은 속도 제한 적용

## 2D 구현
캐릭터는 아래 투명 PNG 레이어를 순서대로 합성한다.
`background → body → legs → outfit → face → hair → accessories`

MVP는 각 성장값 0~10을 실제 이미지 5단계로 매핑한다.
- 0~1: 이미지 0
- 2~3: 이미지 1
- 4~5: 이미지 2
- 6~7: 이미지 3
- 8~10: 이미지 4

## 안전 원칙
마름, 비만, 실패 같은 가치 판단 문구를 쓰지 않는다. 캐릭터 변화는 추정 시각화이며 의료적 신체 평가가 아님을 표시한다.

## 완료 기준
기준선, 추세, 신뢰도, 속도 제한, 2D 단계 매핑을 확정했다. 다음은 STEP 7 칼로리 시스템이다.
