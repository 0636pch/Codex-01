# STEP 8 — MVP 개발 순서

각 단계가 끝날 때 실제 앱을 실행하며, 다음 단계가 이전 단계의 정상 동작을 깨지 않는지 회귀 테스트한다.

| 순서 | 구현 | 실행 확인 |
|---:|---|---|
| 1 | Flutter 프로젝트, 테마, 라우터 | 시작 화면 표시 |
| 2 | Firebase 프로젝트 연결 | 초기화 오류 없이 실행 |
| 3 | 이메일 회원가입·로그인 | 계정 생성·로그인·로그아웃 |
| 4 | 동의 및 온보딩 진행 저장 | 재실행 시 중단 지점 복귀 |
| 5 | 프로필 입력 | Firestore 사용자 문서 생성 |
| 6 | 최초 인바디 | 선택값·건너뛰기 저장 |
| 7 | 2D 캐릭터 생성 | 레이어 미리보기와 저장 |
| 8 | 하단 탭과 HOME | 캐릭터·레벨·EXP 표시 |
| 9 | 운동 DB와 검색 | 부위·기구 필터 |
| 10 | 근력 세션과 세트 | 중량×횟수×세트 저장 |
| 11 | 유산소 | 시간·거리·심박·칼로리 |
| 12 | 운동 완료 Cloud Function | EXP 중복 없이 1회 지급 |
| 13 | 음식 기록 | 식사별 추가·수정·삭제 |
| 14 | 일일 에너지 요약 | 섭취·소비·밸런스 재계산 |
| 15 | 인바디 추가와 비교 | 이전 대비 변화량 |
| 16 | 캐릭터 기본 변화 | 속도 제한된 단계 변화 |
| 17 | 운동 캘린더 | 날짜별 기록 구분 |
| 18 | 성장 그래프 | 7/30/90일 지표 |
| 19 | 보안 규칙·색인·에뮬레이터 | 타 사용자 접근 차단 |
| 20 | 오류·오프라인·접근성 | 빈 상태와 복구 |
| 21 | Android 내부 테스트 | 실제 기기 설치 및 핵심 흐름 |
| 22 | iOS 점검 | 빌드와 레이아웃 확인 |

## 테스트 기준
- 단위 테스트: EXP, 레벨, 칼로리, 캐릭터 공식
- 위젯 테스트: 입력 검증과 이동
- 통합 테스트: 가입→프로필→인바디→캐릭터→홈
- Firebase Emulator: 보안 규칙과 Functions
- 실제 기기: 키보드, 날짜, 네트워크 중단, 뒤로가기

## 완료 정의
코드 작성, 자동 테스트, 실제 실행, 오류 상태 확인, 문서 갱신이 모두 끝나야 한 단계를 완료로 본다.
