# 사용자 흐름

## 1. 첫 사용 흐름

`시작 → 회원가입 → 개인정보·건강 데이터 동의 → 기본 정보 → 선택적 인바디 → 캐릭터 만들기 → 대시보드`

1. 시작 화면에서 회원가입 또는 로그인을 선택한다.
2. 회원가입에서 이메일, 비밀번호, 닉네임을 입력한다.
3. 필수 동의와 선택 동의를 구분해 확인한다. 필수 동의를 하지 않으면 어떤 기능을 사용할 수 없는지 설명한다.
4. 나이, 키, 체중, 운동 목적, 운동 경험, 평소 활동량을 입력한다.
5. 인바디 결과가 있으면 입력하고, 없으면 건너뛴다.
6. 얼굴형, 머리, 피부색, 체형, 운동복을 직접 골라 캐릭터를 만든다.
7. 대시보드에서 첫 기록을 안내하는 퀘스트를 본다.

중간 이탈 시 민감한 입력값을 기기에 평문으로 남기지 않는 범위에서 진행 상태를 복구합니다. 복구 방식은 추후 결정합니다.

## 2. 기존 사용자 로그인 흐름

`시작 → 로그인 → 대시보드`

- 로그인 실패 시 계정 존재 여부를 과도하게 노출하지 않는 오류 문구를 보여준다.
- 비밀번호 찾기와 이메일 인증 흐름은 인증 방식 확정 후 상세화한다.

## 3. 운동 기록 흐름

`대시보드의 기록 버튼 → 운동 기록 → 저장 확인 → 경험치 이펙트 → 갱신된 대시보드`

1. 근력운동, 유산소, 걷기 중 유형을 선택한다.
2. 공통 정보와 유형별 세부 정보를 입력한다.
3. 예상 소모 칼로리는 앱 추정 또는 직접 입력으로 구분하고 `추정값` 배지를 표시한다.
4. 저장하면 기록과 획득 경험치의 근거를 보여준다.
5. 퀘스트, 능력치, 연속 기록이 바뀌었다면 각각의 이유를 간단히 보여준다.
6. 같은 기록을 반복 저장하지 않도록 처리한다.

## 4. 식사 기록 흐름

`대시보드의 기록 버튼 → 식사 기록 → 끼니 선택 → 음식 추가 → 저장 → 섭취 요약`

- 아침, 점심, 저녁, 간식 중 하나를 선택한다.
- 음식명, 섭취량, 칼로리와 선택적 영양소를 입력한다.
- 섭취 칼로리는 활동 칼로리와 별도 카드에 표시한다.
- 낮은 칼로리나 식사 생략에는 보상하지 않는다.
- 안전 기준에 해당하면 비판하지 않는 안내와 전문 도움 경로를 제공한다. 구체 기준은 추후 결정한다.

## 5. 체중·인바디 갱신 흐름

`대시보드 또는 성장 그래프 → 측정값 추가 → 저장 → 추세 갱신`

- 체중은 날짜별로 추가한다.
- 인바디는 여러 항목을 한 측정 결과로 묶어 저장한다.
- 입력 직후 그래프는 갱신하지만 캐릭터 체형은 단일 값으로 급변하지 않는다.
- 최근 7일 추세가 충분하거나 새 인바디가 들어오면 성장 단계 계산 후보가 된다.

## 6. 성장 확인 흐름

`대시보드 → 성장 그래프 또는 캐릭터와 능력치`

- 성장 그래프: 기간과 지표를 선택하고 값의 추세를 본다.
- 캐릭터 화면: 레벨, 경험치, 네 능력치, 성장 단계, 해금 보상을 본다.
- 변화 이유를 `최근 운동 기록`, `주간 퀘스트 완료`처럼 이해 가능한 문장으로 제공한다.

## 7. 퀘스트와 보상 흐름

`대시보드 퀘스트 → 조건 수행 → 자동 완료 판정 → 경험치·보상 수령`

MVP에서는 기록 저장 시 자동 판정합니다. 별도 수령 버튼의 필요 여부는 추후 결정합니다. 놓친 퀘스트가 사용자를 비난하는 표현을 사용하지 않으며, 연속 기록이 끊겨도 누적 성장은 사라지지 않습니다.

## 8. 설정과 데이터 삭제 흐름

`설정 → 계정 및 데이터 → 내보내기 또는 삭제`

- 내보내기: 포함 항목과 파일 형식을 확인하고 본인 확인 후 생성한다.
- 삭제: 삭제되는 데이터, 처리 기간, 복구 가능 여부를 설명한다.
- 재인증 후 최종 확인을 받고 삭제 요청을 접수한다.
- 법적으로 보관해야 하는 항목이 있다면 항목과 기간을 별도로 안내한다.
- 처리 완료 또는 실패 상태를 사용자가 확인할 수 있게 한다.

## 9. 공통 예외 흐름

- 네트워크 오류: 입력값을 보존하고 재시도 제공
- 인증 만료: 작성 내용을 보호한 뒤 재로그인 안내
- 잘못된 값: 해당 입력칸 가까이에 이유와 허용 범위 표시
- 빈 기록: 죄책감을 주지 않는 시작 안내 제공
- 중복 측정: 덮어쓰기 전에 기존 기록과 선택지를 표시

## 10. 추후 결정 사항

- 온보딩 임시 저장 및 재개 방식
- 퀘스트 보상의 자동 수령 여부
- 운동 템플릿과 최근 기록 복사 기능의 MVP 포함 여부
- 체중·인바디 같은 날짜 중복 입력 처리 방식
- 데이터 내보내기 형식과 전달 방식
- 계정 삭제 유예 기간과 복구 정책
